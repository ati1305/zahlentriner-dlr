Zahlen-Merktrainer – GitHub Pages

1. Erstelle auf GitHub ein neues öffentliches Repository, z. B. zahlen-merktrainer.
2. Lade alle Dateien aus diesem Ordner in das Repository hoch.
3. Öffne im Repository: Settings → Pages.
4. Unter "Build and deployment" wähle:
   Source: Deploy from a branch
   Branch: main
   Ordner: / (root)
5. Speichern. Nach kurzer Zeit erscheint dein GitHub-Pages-Link.
6. Öffne den Link auf dem iPhone in Safari.
7. Teilen → Zum Home-Bildschirm.

Wichtig:
- Führende Null ist erlaubt.
- Die App funktioniert nach dem ersten Laden offline.
- Statistik wird lokal auf dem iPhone gespeichert.
